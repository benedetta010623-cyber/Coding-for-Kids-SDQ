# Student Avatars Directory

Place real student avatar images (WebP format recommended) in this directory:
`public/avatars/`

Examples:
- `public/avatars/alkholifi.webp` -> Access in app via `/avatars/alkholifi.webp`
- `public/avatars/student-name.webp` -> Access in app via `/avatars/student-name.webp`

Recommended Specs:
- Dimensions: 300x300 or 512x512 px square
- Target File Size: 20KB - 80KB
- Format: WebP (or JPG/PNG compressed)
